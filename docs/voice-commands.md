# Voice & Typed Commands Reference

OfferCheck is built for students, graduates, and job seekers who prefer to type or dictate. OfferCheck **never** requests microphone access or calls proprietary speech APIs in the browser. Instead, it accepts text generated by any operating system dictation tool or external speech-to-text application (such as Wispr Flow, Apple Dictation, Windows Voice Typing, or Android/iOS voice input), as well as standard keyboard input.

The Global Command Bar (`/` or `Ctrl+K` / `Cmd+K`) listens for recognized commands, strips spoken conversational filler words, and provides a visible 2-second confirmation countdown before taking action. If a dictated sentence does not match a command or exceeds 80 characters, OfferCheck automatically offers to append it into your offer text.

## Natural Spoken Language & Filler Stripping

Dictated speech frequently begins or ends with conversational filler words. OfferCheck's pure matcher (`src/lib/commands/match.ts`) normalizes spoken input by stripping:

- **Leading prefixes:** `please`, `can you`, `could you`, `would you`, `hey`, `just`, `now`, `go to`, `navigate to`, `switch to`, `show me`, `take me to`, `open`, `open up`, `jump to`
- **Trailing suffixes:** `please`, `now`, `for me`
- **Punctuation:** Trailing question marks, exclamation marks, periods, commas, colons, semicolons
- **Case:** All matching is case-insensitive

**Examples of recognized natural speech:**
- *"Could you please show me observations?"* $\rightarrow$ Jumps to Observations
- *"Hey, take me to privacy policy"* $\rightarrow$ Navigates to `/privacy`
- *"Can you please run review now!"* $\rightarrow$ Triggers analysis
- *"Would you please save as pdf?"* $\rightarrow$ Triggers PDF export dialog

## Long Dictation & Offer Text Integration

When dictating notes, job details, or recruiters' verbal messages:
1. If the input is longer than 80 characters, or if it does not match any predefined command, OfferCheck treats it as dictated offer content.
2. The Command Bar displays a prominent **"Add to offer text"** button with a preview of the text.
3. Clicking or pressing Enter appends the dictated text directly into Step 1 (or the relevant step), preserving every word byte-for-byte.
